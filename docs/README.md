# OBot

A discord bot for various utilities related to Hypixel

Members prove they own a Minecraft account with `/verify`, using the Discord account they linked
on Hypixel. OBot then gives them roles from their Hypixel rank and guild, and can rename them.
Everything is configured per server from a web panel.
